## [v0.1.1] 2026-08-08

### 신규
- 설정에서 파일명에 `입고스케줄관리`가 포함된 Excel 파일을 연결하는 기능 추가.
- 다운로드 후 `Raw_밀크런!C1:P1000`의 값만 지우고 C1부터 값 전용으로 반영하는 기능 추가.
- Excel P열 발주번호를 이용해 안산2의 오늘 일별 입고 상세를 조회하고 거래처, 밀크런 번호, 팔렛트/박스 수, SKU 정보를 6열 표에 표시하는 기능 추가.
- 오류 상세 내용 복사와 GitHub 이슈 신고 기능 추가.
- 설정에서 앱 업데이트 내역을 확인하는 기능 추가.

### 개선
- 실행마다 전용 임시 다운로드 폴더를 사용하고 완성된 지원 파일만 최종 폴더로 이동하도록 안전성 강화.
- CP949/UTF-16/UTF-8 텍스트와 Excel 다운로드 파일의 값 반영 지원.
- Excel 저장 실패 시 기존 범위를 복원하고, 사용자가 열어 둔 파일의 미저장 변경과 읽기 전용 상태를 사전 확인하도록 개선.
- 밀크런 다운로드 후에도 Chrome 로그인 세션을 유지해 일별 입고 상세까지 연속 처리하도록 개선.
