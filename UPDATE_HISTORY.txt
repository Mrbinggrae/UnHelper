## [v0.1.6] 2026-08-08

### 수정
- WMS 상품관리 검색 결과에서 조회한 SKU ID를 첫 번째 열의 내부 SKU가 아니라 두 번째 열의 External ID와 정확히 비교하도록 수정.
- 내부 SKU와 External ID가 다른 상품도 11번째 열의 상품명 링크를 정상적으로 클릭해 상세 무게를 조회하도록 수정.
- 검색 결과가 표시됐는데도 후보를 찾지 못해 30초 뒤 `검색 결과가 안정화되지 않았습니다`로 실패하던 문제를 해결.

## [v0.1.5] 2026-08-08

### 디자인
- 메인 화면, RAW 표, 설정, 오류 신고, 업데이트 내역, 상품 메모리를 Slate/Navy 계열의 현대적인 다크 테마로 전면 개편.
- 메인 탭과 하위 탭의 계층을 분리하고 표·입력창·버튼·로그·스크롤바의 색상과 상태 표현을 일관되게 정리.
- 설정 항목을 카드형 섹션으로 묶고 작은 화면에서는 내용만 스크롤되며 저장 버튼은 항상 접근할 수 있도록 개선.

### 변경
- WMS 상품관리 조회 결과에서 첫 번째 열의 SKU ID가 정확히 일치하는 행만 선택하고, 11번째 열의 상품명 링크를 클릭해 상세를 열도록 변경.
- 상품명 링크의 `target` 값에 의존하지 않고 실제 새 탭 또는 현재 탭 이동을 감지하며, 상세의 `input.hidden-weight` 값으로 상품 무게를 확인하도록 보강.
- 모든 Milkrun 배차와 상세 상품 목록 수집이 끝난 뒤에만 WMS 상품관리 조회를 시작하는 실행 순서를 회귀 테스트로 고정.

### 개선
- 주요 버튼의 글자 대비와 분류 상태 색상을 개선하고, 긴 거래처명과 SKU명은 툴팁으로 전체 내용을 확인할 수 있도록 개선.

## [v0.1.4] 2026-08-08

### 신규
- 오류 팝업에서 GitHub 로그인 없이 UnHelper 저장소로 이슈를 자동 등록하고, 같은 오류가 다시 발생하면 기존 열린 이슈에 댓글로 추가하는 기능 추가.

### 변경
- WMS `상품 관리`의 SKU 조회 입력 대상을 `input.form-control.input-external-id`로 변경.
- RAW > Milkrun의 `팔렛트당 박스`를 WMS 무게 조회와 분리하고 `박스 수 ÷ 팔렛트 수`로 즉시 표시하도록 변경. 예: 팔렛트 1, 박스 2는 `2`로 표시.

### 안정성
- Excel이 일시적으로 호출을 거부하는 `-2147418111` 오류가 발생하면 준비 상태를 확인하며 제한적으로 재시도하고, 반영 또는 저장 실패 시 기존 값을 복원하도록 개선.
- 오류 신고 내용의 민감정보를 제거하고 동일 오류를 지문으로 구분하며, 릴리즈 빌드 전에 신고 토큰 형식·인증·저장소 접근과 패키지 포함 여부를 검증하도록 개선.

## [v0.1.3] 2026-08-08

### 변경
- 일별 입고 상세 조회 기준을 `Raw_밀크런` P열 발주번호에서 다운로드 첫 시트 A열 배차번호로 변경하고, 배차번호에 `M` 접두사를 붙여 Milkrun 카드와 연결하도록 변경.
- 어제 입고 행을 제외한 오늘 데이터의 배차번호를 중복 없이 수집하고, A열이 빈 연속 상품 행은 허용하되 유효한 배차번호가 없거나 형식이 잘못된 경우 Excel을 변경하기 전에 오류로 안내.

### 개선
- 일별 입고 카드에서 실제 `M` 접두사가 있는 Milkrun 카드만 정확히 매칭해 `T` 카드나 숫자 전용 카드를 잘못 선택하지 않도록 개선.
- GitHub 이슈 신고 주소에서 긴 오류 본문을 제거해 `Whoa there!` 페이지로 이동하는 문제를 해결하고, 민감정보를 가린 전체 보고서를 클립보드에 복사한 뒤 `Ctrl+V`로 붙여넣도록 안내.

## [v0.1.2] 2026-08-08

### 신규
- 설정에 Windows DPAPI로 보호되는 WMS ID/Password 입력 기능 추가.
- 일별 입고 SKU를 WMS `재고관리 > 상품관리`에서 조회해 상품 무게와 1팔렛트 중량을 표시하는 기능 추가.
- 1팔렛트 중량 280kg를 기준으로 경량/중량을 자동 분류하고, 행별 단일 버튼으로 경량/중량/고단을 수동 변경하는 기능 추가.
- SKU별 상품 무게와 수동 분류를 로컬에 저장해 다음 실행의 WMS 재조회를 생략하는 기능 추가.
- 설정에서 저장된 상품 분류 목록을 확인하고 JSON으로 가져오기/내보내기·선택 삭제하는 기능 추가.

### 변경
- 다운로드 데이터의 첫 번째 시트 C열 `입고일`을 검사해 어제 날짜 행을 제외한 뒤 `Raw_밀크런`에 반영하도록 변경.
- RAW Milkrun 표를 상품 무게, 팔렛트당 박스, 1팔렛트 무게, 단일 분류 버튼을 포함한 10열로 확장.
- 상품명의 줄바꿈은 공백으로 정리하되 `/` 문자는 나누거나 삭제하지 않고 그대로 보존.

### 개선
- WMS 검색 결과를 정확한 SKU ID와 새 결과 전환으로 검증하고 빈 값·0 이하 무게를 오류 처리.
- 일부 SKU 조회 실패 시 성공 결과와 캐시는 유지하면서 GitHub 신고가 가능한 오류 팝업으로 안내.
- 저장 상품 JSON을 완전 검증한 뒤 원자적으로 저장하고 기존 SKU 우선 방식으로 안전하게 병합.

## [v0.1.1] 2026-08-08

### 신규
- 설정에서 파일명에 `입고스케줄관리`가 포함된 Excel 파일을 연결하는 기능 추가.
- 다운로드 후 `Raw_밀크런!C1:P1000`의 값만 지우고 C1부터 값 전용으로 반영하는 기능 추가.

- 설정에서 앱 업데이트 내역을 확인하는 기능 추가.

### 개선
- 실행마다 전용 임시 다운로드 폴더를 사용하고 완성된 지원 파일만 최종 폴더로 이동하도록 안전성 강화.
- CP949/UTF-16/UTF-8 텍스트와 Excel 다운로드 파일의 값 반영 지원.
- Excel 저장 실패 시 기존 범위를 복원하고, 사용자가 열어 둔 파일의 미저장 변경과 읽기 전용 상태를 사전 확인하도록 개선.
- 밀크런 다운로드 후에도 Chrome 로그인 세션을 유지해 일별 입고 상세까지 연속 처리하도록 개선.
